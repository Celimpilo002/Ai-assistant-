AI Assistant

Project Overview

AI Assistant is an AI-powered workplace productivity application designed to help users complete common workplace tasks more efficiently. The application combines multiple AI-powered features into one simple and user-friendly platform.

Features

1. Smart Email Generator

- Generates professional workplace emails.
- Supports different communication tones, including formal, friendly and persuasive.
- Helps users save time when writing emails.

2. Meeting Notes Summarizer

- Summarizes long meeting notes.
- Identifies important decisions.
- Extracts action items and deadlines.

3. AI Task Planner / Scheduler

- Helps users organize daily and weekly tasks.
- Prioritizes tasks according to importance.
- Creates structured schedules to improve productivity.

4. AI Research Assistant

- Helps summarize information about different topics.
- Provides useful insights and recommendations.
- Helps users understand information more quickly.

5. AI Chatbot

- Provides an interactive workplace AI assistant.
- Responds to user prompts.
- Helps users with workplace questions and productivity tasks.

Tools Used

- GitHub
- HTML, CSS and JavaScript
- AI tools such as ChatGPT
- Prompt engineering
- GitHub repository for version control

Setup Instructions

1. Clone or download this repository.
2. Open the project folder.
3. Open the application in a web browser.
4. Follow the instructions displayed in the application.
5. Enter a prompt or task and use the relevant AI feature.

Responsible AI

The application is designed to support users rather than replace human judgment. Users should review AI-generated information before using it for important workplace decisions. Personal, confidential or sensitive information should not be entered into the application unnecessarily.
